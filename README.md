# Arch Rice

My personalised Arch Linux and Hyprland environment.

## Themes

- Arasaka: Cyberpunk-inspired interface
- Yoru: Monochrome anime aesthetic
- Lighthouse: Animated fantasy landscape
- Snoopy: Relaxed, cosy desktop

## Goals

- Learn Arch Linux and Hyprland
- Build multiple switchable themes
- Learn Neovim and shell scripting
- Keep the configuration portable using Git
